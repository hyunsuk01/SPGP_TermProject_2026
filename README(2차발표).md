# Memory Route - 2차 발표

## 1. 게임 소개
**Memory Route**는 플레이어의 이동 경로를 기록하고, 이후 자신의 움직임을 그대로 재현하는 **'분신(Shadow)'**와 협력하여 목적지에 도달하는 **2D 퍼즐 액션 게임**입니다. 과거의 나(분신)이 현재의 나를 돕거나 방해할 수 있는 시차적 협력 메카닉이 핵심입니다.

---

## 2. 현재까지의 진행 상황 (중간 보고 시점)
1차 발표 당시 세웠던 계획을 바탕으로, 현재 핵심 메카닉의 대부분을 실제 코드로 구현 완료했습니다.

| 항목 | 진행 정도 | 세부 내용 |
| :--- | :---: | :--- |
| **캐릭터 제어** | 100% | 상하좌우 이동 및 상태별(IDLE, RUN, DEATH, CLIMB) 애니메이션 구현 완료 |
| **그림자(분신) 시스템** | 100% | 플레이어 이동 이력 기록 및 과거 경로 재현 로직 구현 완료 |
| **맵 오브젝트 구현** | 100% | 버튼, 발판, 사다리, 깃발 등 핵심 상호작용 요소 구현 완료 |
| **퍼즐 상호작용** | 90% | 플레이어/분신의 버튼 입력에 따른 발판 활성화 로직 완료 |
| **게임 규칙 및 물리** | 90% | 분신 충돌 판정, 맵 이탈 추락, 사망 후 스테이지 리셋 구현 완료 |
| **조작 UI** | 80% | 이동 경로 시각화 슬롯 및 화면 Overlay 조작 버튼 배치 완료 |

> **[진행률 산정 근거 및 미달성 사유]**
> - **퍼즐 상호작용 (90%)**: 현재 버튼-발판-사다리의 핵심 기믹은 구현 완료되었으나, 다양한 퍼즐 요소의 추가 구현이 남아 있음.
> - **게임 규칙 및 물리 (90%)**: 기본 물리 판정은 완료되었으나, 캐릭터가 특정 타일에 끼이거나 분신과의 충돌 판정 시 발생할 수 있는 예외 상황에 대한 예외 처리 로직 고도화 진행 중.
> - **조작 UI (80%)**: 인게임 방향키와 슬롯 UI는 배치 완료되었으나, 게임의 완성도를 위한 '일시정지 메뉴(Pause)', '스테이지 선택 화면', '사운드 On/Off 설정' 등 시스템 UI의 부재로 인해 80%로 산정함.

## 5. 시스템 구성 및 설계

### Activity 구성
- **MainActivity**: `GameView`를 호스팅하며, 하단 조작 버튼(`ImageButton`)들의 클릭 이벤트를 게임 로직으로 연결합니다.
- **activity_main.xml**: `FrameLayout`을 사용하여 게임 화면 위에 조작 UI를 Overlay 하였습니다.

### Scene 구성 및 전환 관계
- **MainScene (GameView)**: `onDraw` 루프 내에서 실시간으로 이동, 충돌, 애니메이션이 처리됩니다.
- **상태 전환(State)**: 
  - `IDLE` ↔ `RUN`: 이동 시 전환.
  - `IDLE/RUN` → `DEATH`: 충돌/추락 시 전환되며, 1초 후 `resetStage()`가 실행됩니다.
  - `IDLE` → `CLIMB`: 사다리 이용 시 수직 이동 애니메이션으로 전환됩니다.

## 6. Game Objects 상세 정보 (MainScene)

### **Class: GameView**
게임의 핵심 렌더링과 물리 로직을 책임지는 메인 클래스입니다.

#### **1. 클래스 구성 정보**
- **그림 구성**: `drawMapAssets`에서 맵을, `drawCharacter`에서 플레이어/분신 스프라이트를 상태에 맞춰 그립니다.
- **동작 구성**: `moveToward` 메서드를 통해 매 프레임 좌표를 부드럽게 보간하여 이동시킵니다.

#### **2. 상호작용 정보**
- **버튼(Index 17) - 발판(Index 11)**: `isSwitchPressed` 변수를 통해 플레이어 또는 분신이 버튼 위에 있을 때만 발판을 활성화합니다.
- **사다리(Index 14/2)**: 특정 인덱스에서 `moveUp/Down` 호출 시 Y축 좌표를 조절하여 층간 이동을 수행합니다.

#### **3. 핵심 코드 설명**
```kotlin
// 플레이어의 과거 경로를 분신이 재현하는 핵심 로직
private fun moveShadow() {
    if (replayIndex >= moveHistory.size) return
    when (moveHistory[replayIndex]) {
        Direction.RIGHT -> { shadowTargetX += tileSizeX; shadowFacingRight = true; shadowState = State.RUN }
        Direction.LEFT -> { shadowTargetX -= tileSizeX; shadowFacingRight = false; shadowState = State.RUN }
        Direction.UP -> { /* 사다리 판정 후 수직 이동 */ }
        Direction.DOWN -> { /* 사다리 판정 후 수직 이동 */ }
    }
    shadowMoving = true
    replayIndex++
}

- **코드 역할**: `moveHistory` 리스트에 저장된 플레이어의 이동 이력을 순차적으로 꺼내어 그림자의 `shadowTargetX/Y`를 갱신함으로써 과거 경로를 완벽히 재현합니다.
- **기획 의도**: 과거의 나(그림자)와 현재의 내가 상호작용하게 함으로써 단순한 액션을 퍼즐의 영역으로 확장했습니다.

#### **4) UX 진행 방법**
- **계획적 UI (Visual Planning)**: 상단 **이동 슬롯(Move Slots)**에 현재 입력된 방향 아이콘을 표시하여, 사용자가 자신의 이동 경로를 시각적으로 복기하고 다음 수를 전략적으로 수립할 수 있도록 돕습니다.
- **명확한 피드백 (Feedback Loop)**: 캐릭터 사망 시 전용 애니메이션(`DEATH`)을 출력하고 즉시 리셋하지 않는 지연 시간을 두어, 사용자가 실패 원인(그림자 충돌, 맵 이탈 등)을 명확히 인지한 후 다시 도전할 수 있게 설계했습니다.
- **학습 곡선 설계 (Learning Curve)**: 초반에는 단순 이동으로 규칙을 익히고, 중반부터 버튼과 분신을 복합적으로 활용해야 하는 퍼즐을 배치하여 사용자가 자연스럽게 게임의 심화 메카닉에 숙련되도록 유도합니다.
- **시각적 일관성 (Consistency)**: 기기 해상도에 관계없이 동일한 비율의 화면을 제공하기 위해 모든 오브젝트를 `tileSize` 비율 기반으로 계산하여 렌더링함으로써 사용자에게 균일한 플레이 경험을 제공합니다.
